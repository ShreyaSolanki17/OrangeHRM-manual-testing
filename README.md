# OrangeHRM Manual Testing Project

## Project Overview

This project documents a manual QA workflow for the OrangeHRM demo
application. It will cover requirements understanding, test design, manual
execution, defect reporting, retesting, regression testing, and final
reporting.

## Application Under Test

- **Application:** OrangeHRM Demo
- **Primary modules:** Login, PIM / Employee Management, and Leave Management

## Current Scope

The initial testing scope is:

- Login and logout/session behavior
- Employee search and employee management flows in PIM
- Leave-related pages, filters, validation, and available workflows
- Functional, UI, positive, negative, boundary/validation, and regression
  testing where applicable

Execution results and defect counts will be recorded only after the relevant
tests are performed.

## Repository Structure

```text
Test-Plan/       Test strategy, scope, entry/exit criteria, and risks
Test-Cases/      Detailed test cases and execution data
Bug-Reports/     Defect summary and supporting screenshots
Test-Evidence/   Screenshots and other execution evidence
Test-Summary/    Final execution summary and conclusions
```

## Project Status

**Phase 1 — Project setup and application exploration**

The repository structure and project overview are established. The next
milestone is to document the test plan and application scope before creating
detailed scenarios and test cases.
